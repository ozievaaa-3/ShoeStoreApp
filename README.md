# ShoeStoreApp — система управления магазином обуви

Учебный проект: десктопное приложение для работы с каталогом товаров и заказами магазина обуви ООО «Обувь».

## Функциональность

- Авторизация пользователей.
- Вход в систему в гостевом режиме.
- Просмотр каталога обуви.
- Поиск товаров и фильтрация по поставщику.
- Сортировка товаров.
- Просмотр списка заказов.
- Добавление и редактирование товаров.
- Создание и редактирование заказов.
- Работа с базой данных PostgreSQL.

## Используемые технологии

- Python 3.
- Tkinter — графический интерфейс.
- PostgreSQL — система управления базами данных.
- psycopg2 — подключение к PostgreSQL.
- pandas — обработка данных.
- Pillow — работа с изображениями.

## Требования

- Python 3.
- PostgreSQL.
- Библиотеки из файла requirements.txt.

## Установка и запуск

1. Клонировать репозиторий:

   `git clone <адрес репозитория>`

2. Перейти в папку проекта:

   `cd ShoeStoreApp`

3. Создать виртуальное окружение:

   `python -m venv venv`

4. Активировать окружение:

   `venv\Scripts\activate`

5. Установить зависимости:

   `pip install -r requirements.txt`

6. Создать базу данных PostgreSQL с именем `shoestore_db`.

7. Выполнить SQL-скрипт `create_tables.sql` в созданной базе данных.

8. Скопировать `config.ini.example` в `config.ini` и указать собственные параметры подключения к PostgreSQL.

9. Запустить приложение:

   `python main.py`

## Структура проекта

- `main.py` — точка входа в приложение.
- `auth_window.py` — окно авторизации.
- `products_window.py` — окно каталога товаров.
- `orders_window.py` — окно заказов.
- `order_create_window.py` — создание заказа.
- `order_edit_window.py` — редактирование заказа.
- `product_create_window.py` — добавление товара.
- `product_edit_window.py` — редактирование товара.
- `database.py` — взаимодействие с базой данных.
- `models.py` — модели данных.
- `insert_data.py` — импорт данных.
- `create_tables.sql` — создание таблиц базы данных.
- `resources/` — изображения, логотип и иконки.
- `data/` — файлы исходных данных.
- `config.ini.example` — образец конфигурации подключения.

## База данных и ER-диаграмма

База данных проекта предназначена для хранения информации о пользователях, товарах, заказах, пунктах выдачи и позициях заказов.

Основные таблицы:
- users — пользователи системы;
- products — каталог товаров;
- pickup_points — пункты выдачи;
- orders — заказы;
- order_items — позиции заказов.

Структура базы данных определяется SQL-скриптом create_tables.sql.

С визуальной схемой базы данных можно ознакомиться в файле: [ER-диаграмма](docs/ER-диаграмма.png).
