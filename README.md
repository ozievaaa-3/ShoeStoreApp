# ShoeStoreApp

## Описание проекта

ShoeStoreApp — настольное приложение для автоматизации работы магазина обуви. Приложение позволяет управлять товарами, заказами, пользователями и пунктами выдачи.

## Основные возможности

- Авторизация пользователей.
- Просмотр списка товаров.
- Поиск, фильтрация и сортировка товаров.
- Добавление, редактирование и удаление товаров.
- Просмотр и управление заказами.
- Создание и редактирование заказов.
- Работа с пунктами выдачи.

## Используемые технологии

- Python
- Tkinter
- PostgreSQL
- psycopg2
- pandas

## Структура проекта

- `main.py` — запуск приложения.
- `auth_window.py` — окно авторизации.
- `products_window.py` — окно товаров.
- `orders_window.py` — окно заказов.
- `database.py` — работа с базой данных.
- `models.py` — модели данных.
- `config.py` — загрузка настроек подключения.
- `config.ini.example` — пример настроек базы данных.
- `create_tables.sql` — SQL-скрипт создания таблиц.
- `resources/` — ресурсы приложения.
- `data/` — файлы с данными.
- `sql/` — дополнительные SQL-файлы.

## Установка и запуск

1. Склонировать репозиторий.
2. Установить необходимые зависимости командой:

   `pip install -r requirements.txt`

3. Создать файл `config.ini` на основе `config.ini.example`.
4. Указать параметры подключения к PostgreSQL в `config.ini`.
5. Создать базу данных `shoestore_db`.
6. Выполнить SQL-скрипт `create_tables.sql`.
7. Запустить приложение:

   `python main.py`

## Безопасность

Файл `config.ini` содержит локальные настройки подключения к базе данных и не добавляется в репозиторий. Для настройки нового рабочего места используется `config.ini.example`.
